# 保护模型

这份文档讲的是：**这套东西靠什么拦住你自己，以及它拦不住什么。**

写给要用它的人，不是写给读代码的人。里面的数字和判断都对着代码核过。

---

## 一句话

它不是防别人，是防**凌晨一点的你自己**。

所以设计目标不是"技术上不可能绕过" —— 你是管理员，技术上没有什么你做不到的 ——
而是**让每一次放宽都要付出一次刻意的代价**，并且让"偷偷放宽"这件事留下痕迹。

---

## 两个进程

装完之后有三个东西在跑，它们的分工是这个模型的地基：

| | 是什么 | 谁启动 | 权限 |
|---|---|---|---|
| **Sentinel.Service.exe** | 后台服务。**配置的主人**：所有保存都要经过它，令牌由它判 | Windows 服务，开机自启 | SYSTEM |
| **Sentinel.Agent.exe** | 你看到的那个：托盘图标、设置窗口、**跑监控的那个循环** | 服务把你登录会话里的它拉起来 | 普通用户（你） |
| **SentinelWatchdog** | 计划任务，每分钟跑一次 | Windows 任务计划程序 | SYSTEM |

**为什么配置的主人是服务，而不是你那个窗口**：你在窗口里改的每一样东西，都是发给服务、由服务
判定并落盘的。你的窗口没有直接写配置的权限，所以**关掉界面、杀掉界面进程，都不能改配置**。

---

## 装完之后，权限被设成这样

| 位置 | 你的权限 | 为什么 |
|---|---|---|
| `<安装目录>\bin\`（程序） | **只读** | 否则你（或任何程序）把 `Sentinel.Service.exe` 换掉，配合失败自动重启，下一次开机就以 SYSTEM 跑替换后的代码 |
| `config.json` | **只读** | 这是"延迟解锁"能成为一把锁而不是一层摩擦的前提 |
| `logs\`（本地审计） | **可写** | 监控是以你的身份跑的，它得能写。所以**这份记录改得动** |
| `audit\`（权威审计） | **只读** | 服务写的。**这份改不动** —— 它才是证据 |
| `vault\`（保险箱密文） | **可写** | 要往里放文件。能写不等于能读：里面每个文件都是加密且带认证的 |
| `.vault-seal`（封印标记） | **只读** | 权威的封印状态放在这里，"拷回一份旧备份"没有用 |

服务的权限也被收紧了：**管理员不能从服务控制台、任务管理器或 `sc stop` 停掉它**。
要停得先用 `sc sdset` 把权限改回去 —— 两条刻意的命令，而且看门狗每分钟把它改回收紧状态。

## 解锁保护

### 钥匙在哪

- **私钥**：在你**手机上的保险箱**里，或者任何不在电脑上的地方。
- **公钥**：明文放在配置旁边，谁都能读 —— 公钥不是秘密，秘密是"那半把钥匙不在这台机器上"这个事实。

### 流程

1. 你在电脑上做一个**会放宽限制**的修改，点保存 → 被拒，界面给你一段**解锁码**。
2. 把解锁码拿到另一台设备，用 `sentinel-sign.html`（签名页）用私钥签一次，得到一个**令牌**。
3. 把令牌贴回电脑 → 服务验签、验新鲜度、验内容对得上 → 这一次修改才生效。

签名页是一个**本地 HTML 文件**，不联网（你可以断网打开来确认这一点）。

### 有效期怎么算 —— 24 小时，从**生成解锁码那一刻**起

- 点「获取解锁码」的时候，过期时刻就已经写进那段被签名的内容里了：**当时 + 24 小时**。
- 不是从你签名算，也不是从你贴回来算。**是从你要码的那一刻算。**
- 过期时间是**绝对的**（UTC 时间戳，签在内容里），所以本机改系统时间没用 ——
  它是拿"现在"和那个签过名的时间戳比。
- 实际影响：**当天要不出来就作废，重新要一份**。24 小时是"够你走到另一台设备再走回来"。

### 两处生效 —— 令牌能放行的操作只有两种

| # | 什么操作 | 判的代码 |
|---|---|---|
| 1 | **任何会放宽限制的配置修改**（停掉目标、删规则、放宽策略、停用模型监督……） | `ConfigAuthority.Authorize` |
| 2 | **关闭解锁保护本身** | `ConfigAuthority.ValidateDigest`（摘要固定为 `ReleaseDigest`） |

两处都在**服务**（SYSTEM）里判。界面里没有任何一条绕过它们的路径 —— 界面只是把令牌递给服务。

### 另一层：有效期在**签名页**也会拦一下（但那不是防线）

签名页在签之前会看这张解码码过没过期，过期就直接告诉你「回 Sentinel 重新要一份」
（`sentinel-sign.html`）—— 省得你白跑一趟、拿着一个注定会被拒的令牌回来。

**但这只是便利，不是防线。** 签名页是一个本地 HTML 文件，你能改它。真正说了算的是服务那一步：
不管签名页放不放行，过期的令牌贴回来一定会被拒。

### 还有两条约束

- **一次性**：同一个令牌用过之后会被记进账本，再贴一次会被拒。**"去签一次"不等于"以后都放宽了"。**
- **绑定整份配置**：令牌签的是**整份配置的摘要**。要完码之后又改了别的（哪怕是不相关的），
  这张令牌就对不上了 —— 那句话会说"令牌对应的是另一次操作"，重新要一份即可。
- 账本记录保留 **7 天**，之后可以复用同一个非重复令牌空间。

## 保险箱

### 两把钥匙

| | 什么时候能用 |
|---|---|
| **密码** | 正常状态。你自己设的 |
| **监护人解锁码** | **保险箱被封印之后，只有它能开**。生成的时候让你抄下来的那串，放在电脑以外的地方 |

### 什么时候会被封印

封印之后：**密码不再管用，只有监护人解锁码能打开**。以下任意一种：

| 触发 | 阈值 |
|---|---|
| 卸载 Sentinel（默认行为，即使不加 `-Purge`） | 立即 |
| **服务被停掉** | 超过 **10 分钟**（崩溃不算 —— 崩溃由失败恢复在 5 秒内拉回来） |
| **看门狗不再运行**（被禁用、或不在了） | 超过 **5 分钟** |

**为什么要这样：** 把服务停掉十分钟、或者把看门狗禁掉，都是"拆掉那两层防护"的动作。
封印是这件事的后果 —— 想继续用保险箱，就得跑一趟监护人。**这是这套东西约束自己的主要方式。**

**正常重启不会被封印**：机器关机再开机不算 —— 服务分得清"机器没开"和"服务被停了"。

## 看门狗每分钟做的事

1. **把服务的权限改回收紧状态**（你或别的程序放松过，它改回来）
2. **服务不在就把它拉起来**（"停掉服务"这条路的封堵）
3. 留一句"我来过" —— 服务靠它发现**看门狗自己**被停掉了

它注册成 SYSTEM 的计划任务，每分钟一次。

## 审计日志

一份记录，两个位置：

- `logs\audit-YYYYMMDD.jsonl` —— 监控进程写的，**你改得动**（所以它是"顺手能看"的那份）
- `audit\audit-YYYYMMDD.jsonl` —— 服务写的，**你改不动**（所以它才是证据）

里面记的是：什么时候、哪个目标、命中哪条规则、执行了什么动作、以及**当时对你说了什么**
（不然"没发生什么"和"提醒过但你错过了"就分不出来）。

看的地方：「日志」页。

## 挡得住什么，挡不住什么

### 挡得住

- 顺手关掉界面 / 杀掉界面进程 → 监控照跑，配置照旧
- 顺手停掉服务 → 起不来（权限被收走），而且十分钟后保险箱封印
- 禁用看门狗 → 五分钟内服务封印保险箱
- 直接改 `config.json` → 只读，写不进去
- 拷回一份旧的配置 / 旧的封印标记 → 权威的那份在只读位置，覆盖不了
- 手工改本机时间绕过令牌过期 → 过期时刻签在内容里
- 同一个令牌反复用 → 用过一次就记账

### 挡不住

- **决意的管理员。** 每条拦路的命令都有"先把权限改回去"的解法，那需要几条刻意的命令而不是一次点击。
  这是**设计目标**，不是缺陷 —— 见开头那句。
- **拔掉网线之外的物理手段**：进安全模式、换硬盘、重装系统。到这一步已经不属于"约束自己的习惯"了。
- **服务被停掉之前的那段时间**。监控是每秒级的，但"停掉服务"到"保险箱封印"之间有 10 分钟 ——
  这 10 分钟里配置还是只读的，只是没人执行规则了。
- **界面那份审计**（`logs\`）。你要改它随时能改；改不动的只有服务那份。

## 出问题的时候

| 症状 | 去哪儿看 |
|---|---|
| 配了规则但不生效 | 「诊断」页 → 测一次模型监督 / 测试读取 |
| 模型监督不生效 | 「诊断」页的自检会把每一步摊开：窗口对不对、读到什么、规则类型对不对、模型怎么说 |
| 说"配置没有保存" | 状态栏 + 弹窗里会写原因；「规则」「策略」页下方有校验结果 |
| 保险箱打不开 | 它**被封了**。看保险箱窗口里写的封印原因；用监护人解锁码开 |
| 服务起不来 | 事件查看器 → Windows 日志 → 应用程序，找 `Sentinel.Service` |
| 装完没看到托盘图标 | 注销一次再登录；服务负责把你会话里的界面拉起来 |

---

## 最后

这套东西的价值不在于"你破解不了它"，而在于它把"我又放宽了一次"这件事
**从一秒的冲动变成一次要走出房间的操作**。

如果哪天你觉得它太碍事 —— 那正是它在工作。
