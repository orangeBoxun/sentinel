## 这一版的主题：从"一个模型说了算"变成"一条链、两种判断"

### 1. 判断链（责任链）

一个模型判错，整件事就没有第二道关口。现在每个服务商都给**两种判断**：

- **正常判断**：拦不拦，看它。
- **从严判断**：只回答一个问题 —— 这一页要不要交给链上下一个模型。

规则很短：

```
两个判断一致      → 定论（拦 / 放）
两个判断不一致    → 交给链上下一个模型
某个模型调用失败  → 跳过它，问下一个
全链都失败        → 停止发新的判定请求，并按 30 秒的节奏提醒
链尾的模型        → 只看正常判断（后面没人了，从严没有意义）
```

配套的几件事：

- **「稳定提供服务」标记**：链上至少要有一个。它挂了，监督不会停（还会继续判），但会反复提醒；
  取消勾选等于放宽，需要令牌。
- **整链连通测试**：一次性把链上每个服务商都问一遍，谁慢、谁挂一目了然。
- **自检**：可以走整条链，也可以只问某一个服务商单独测。
- 便宜的先判、贵的兜底：合规页面通常在第一个模型就定论，只有"拿不准"的才往下走。

### 2. 「大语言模型」页重做

- 顶部三个视图：**所有供应商** / **判断链** / **用量**。
- 判断链可以拖拽排序（带跟着走的影子、让位滑动），删除在右侧；
  「启用新供应商」改成多选弹窗。
- 原来的地址自动补全、拉模型列表、测试连接都保留。

### 3. 用量页（新）

- 五个汇总卡片：请求数、成功/失败、token、缓存命中（服务商上报了才算，没报会标出来）。
- 三张图：按天的折线、各服务商的柱状、占比的饼图。
- 筛选：今天（按小时）/ 近 7 天 / 近 30 天、供应商、指标。
- 悬停有引导线、元素高亮和详情卡（卡片画在画布里，不会跟着鼠标抖）。
- 升级前按天记录的用量归到当天 00:00，不丢。

### 4. 「模型讨论」（新）

用来回答一个很具体的问题：**这一页判错了，禁令该怎么改？**

- 选两个服务商，再填**你认为该不该拦**和理由 —— 这是全场唯一的对错依据，开场就会念出来。
- 先各自独立判一次（和监控用的是同一套提示词，所以看到的就是线上那两个值）。
- 判对错的标准不是"完全判对"，而是**别漏**：正常判错没关系，只要从严能把这类页面判出来，
  它就会交给链上下一个模型兜住；只有"正常和从严一致、而且都错"才会直接定论放走。
- 兜住的一方先指出漏在哪；漏的一方可以答辩（不认同就说清楚），但要照样写补丁；
  兜住的一方再逐条回应。上一轮的交锋会带进下一轮。
- 补丁会被**真的加进禁令、重新判这一页**（不带任何讨论内容，就是一次普通判定）；
  不过就继续改，通过了才收工。
- 过程是群聊界面（头像、气泡、左右分开），**输入框一直能用**：你随时发一句，
  下一次模型开口前就会带上；每 3 / 5 / 10 轮停下来问一次要不要继续，也可以选「不限轮数（自动跑）」。
- 通过后单独弹一个补丁窗：可以直接**追加到这条目标的「模型监督」规则并保存**，也可以只复制。

### 5. 稳定性

- 图表悬停时疯狂抖动（两处）和"鼠标一移上去就崩进程"都修了。
- 判断链拖拽：影子跟着走、原行让位、换位按布局位置算，不再鬼畜。
- 讨论窗口：继承了主题"固定高度输入框"、被建在线程池线程上（STA 异常）、
  剪贴板被占用时异常炸穿界面 —— 都修了。

## 升级到这一版要知道的

- **旧配置会自动迁移**：原来只配了一个模型，会变成"链上就这一个，并标记为稳定"。
- 判断链至少要保留一个「稳定提供服务」，取消勾选需要令牌。
- 模型讨论会真的发请求：一轮 4~5 次。默认每 3 轮停下来问你，不想一直盯着就选「不限轮数」。
- 配置文件版本未变（仍是 1），其余设置原样保留。

## 安装 / 升级

需要**管理员权限**的 PowerShell（要停服务、改 SYSTEM 目录、重建看门狗任务）：

```powershell
.\install.ps1 -InstallDir "E:\Sentinel" -Source ".\payload"
```

图形安装程序：双击 `Sentinel.Setup.exe`。

升级会保留现有的配置、日志、保险箱和暂停账本；服务与代理程序会被停止并重新启动。
